# MAX Chat

Веб-клиент мессенджера в стиле **MAX**, работающий поверх [GREEN-API](https://green-api.com/) (методы мессенджера MAX): авторизация по инстансу, список чатов, переписка, отправка и приём сообщений в реальном времени, поиск чата по номеру телефона.

**[Перейти на веб-приложение](https://green-chat-seven.vercel.app/)**

**[GREEN-API — консоль и документация](https://console.green-api.com/)**

---

## 🚀 **Основные технологии**

- **React**: Библиотека для создания пользовательских интерфейсов.
- **Tailwind CSS + @base-ui/react**: Утилитарные стили и headless UI-примитивы (собственные компоненты в `shared/ui`).
- **React Router**: Библиотека для роутинга в SPA приложениях.
- **React Hook Form + Zod**: Управление формами и схемная валидация.
- **Axios**: HTTP client (запросы к GREEN-API).
- **Vite**: Модульный сборщик и dev-сервер.
- **TypeScript**: Язык программирования, расширяющий JavaScript статической типизацией.
- **ESLint**: Инструмент для анализа кода с целью выявления проблем в JavaScript/TypeScript коде.
- **Prettier**: Инструмент для автоматического форматирования кода.

## ⚙️ **Переменные окружения**

Приложению **не требуются** переменные окружения для сборки или запуска. Доступ к GREEN-API настраивается прямо в интерфейсе на экране входа:

- `idInstance` — идентификатор инстанса
- `apiTokenInstance` — токен инстанса
- `apiUrl` — адрес API (по умолчанию `https://api.green-api.com`)

Эти данные можно получить в [консоли GREEN-API](https://console.green-api.com/); они сохраняются в `localStorage` браузера.

> Для приёма входящих сообщений в консоли инстанса нужно очистить `webhookUrl` и включить уведомления (incoming/outgoing).

## 🧑‍💻 **Локальный запуск**

```bash
yarn install
yarn dev
```

После запуска приложение будет доступно по адресу **[http://localhost:5173](http://localhost:5173)**.

Доступные скрипты:

```bash
yarn dev        # dev-сервер (Vite)
yarn build      # продакшн-сборка в dist/
yarn preview    # предпросмотр собранной версии
yarn typecheck  # проверка типов (tsc)
yarn lint       # проверка ESLint
yarn format     # форматирование Prettier
```

---

## 🐳 **Запуск через Docker**

В репозитории есть `Dockerfile` (multi-stage: сборка Vite → раздача статики через nginx). Собрать и запустить образ:

```bash
docker build -t max-chat .
docker run -d -p 8080:80 --name max-chat max-chat
```

После запуска приложение будет доступно по адресу **[http://localhost:8080](http://localhost:8080)**.
